# ADR-000 — Architecture Decision Record Template
# Nexgradia — Intelligent Campus Placement & Career Intelligence Platform

> **How to use this template:**
> 1. Copy this file and name it `ADR-NNN-short-title.md` (e.g., `ADR-001-framework-selection.md`).
> 2. Fill in all sections.
> 3. Set Status to `Proposed`.
> 4. Present to team for discussion.
> 5. After team agreement, update Status to `Accepted` and record the date.
> 6. Never delete superseded ADRs — instead create a new ADR and link back.
